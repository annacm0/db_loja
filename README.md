# DB Loja Python

Projeto desenvolvido durante meus estudos de Python e Banco de Dados, utilizando SQLite para realizar operações de cadastro e consulta de produtos.

## Tecnologias utilizadas

- Python
- SQLite3
- SQL

## Funcionalidades

- Conexão com banco de dados SQLite.
- Criação de tabela de produtos.
- Cadastro de produtos.
- Listagem de produtos.
- Persistência de dados.

## Como executar

1. Clone o repositório:

   `git clone https://github.com/annacm0/db_loja.git`

2. Entre na pasta do projeto:

   `cd db_loja`

3. Execute:

   `python db_loja.py`

## Aprendizados

Prática de operações CRUD, consultas SQL, funções Python, cursores e manipulação de banco de dados SQLite.
